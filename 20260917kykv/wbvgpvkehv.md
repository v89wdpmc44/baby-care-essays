# 7月30日开始报名！海南省人民医院专培招生等你来

> 更新时间：2026-09-17 (UTC+8)

海南省人民医院2022年专科医师规范化培训7月30日开始报名啦！

**1.医院介绍**

  //  

海南省人民医院经过百年的历史积淀和淬炼，现已发展成为集医疗、急救、科研、教学、预防、保健、康复于一体的全省规模最大、综合实力最强的首家“三级甲等”综合性医院和省直属公立医院，为保障琼州大地百姓健康做出了突出的历史贡献，也为步入国内大型综合性医院的先进行列，走上与国际接轨的征程奠定坚实的基础和创造良好的条件。        全院职工4533人，高级职称905人，硕博人员942人，卫生部（卫计委）有突出贡献的中青年专家1名,享受政府特贴专家9名,省有突出贡献的优秀专家20名，省领军人才31名，省拔尖人才54名，省“515第一层次”人才工程9人。2020年9月，医院4个团队获评海南省“双百”团队。

目前，业务用房面积计28万平方米，共有2个院区，编制床位2500张,开放床位近3000张。有15个医学中心，81个临床医技科室，23个研究室（实验室）。1个临床医学研究院，下设10个研究所，3个研究中心，1个省重点实验室。有6个国家重点建设专科，8个省重点学科，32个省级重点专科。打造了肝胆病学、心脑血管病介入、医学影像学、泌尿腔镜技术、老年病学、康复医学等一批具有影响力的优势学科群。      海南省人民医院在大力推进高级卒中中心、胸痛中心、创伤中心、中毒中心、房颤中心、危重孕产妇救治中心、危重新生儿救治中心等7个中心建设的同时，在腔镜手术、微创技术、器官复苏、急危重症院前救治、肿瘤介入、血管介入等方面也取得了突出成就。年开展大型危重手术2万余台，微创手术覆盖神经外科的所有治疗领域。

       作为全省唯一一家获批消化系统恶性肿瘤疑难病症诊治能力提升工程项目的医院，该项目入选国家疑难病症诊治能力提升工程项目储备库，是建设高层次临床研究人才的培养基地，是完善海南省消化系统恶性肿瘤疑难病症医疗服务体系的助推器。

      目前全院有110个护理单元，护士2212人，护士长148人，临床一线护士占全院护士的98.04%。专科护理水平在省内占引领地位，拥有国家级专科护士资质的人员有126人，获批护理管理、手术室护理、康复护理3个专业国家级专科护士京外临床教学基地,同时也是省内最大的专科护士培训基地。通过“国家级护理服务标准化试点”建设项目验收，成为国内医疗机构中首家成功申报并通过国家终期评估的单位。

较先进的大型设备有新双源CT、光谱CT、3.0TMR、PET-CT、DSA、医用直线加速器、生化免疫全自动流水线系统、手术机器人等。目前医院医疗设备总值约11.2亿元。

医院设有博士后科研工作站及院士工作站，是海南省医教研重要基地。2021年获批国家自然科学基金16项，总计经费530.1万元，获批项目增长了128%，资助经费增长了121%。省部级项目立项83项，资助经费1191万元，获批项目增长了62%，资助经费增长了34%。此外，海南省教育厅教改科研立项课题8项，海南省社科联哲学课题1项，海南省医学院科研培育基金项目6项，海南省医学院自然科学研究“揭榜挂帅”项目3项。

2021年起医院全面实行综合改革，加快人才布局与优化结构调整，对标国内一流医院，精准引进和培养人才，重视人才培育综合平台和多层次的人才梯队建设，力争到2025年打造成为国内一流综合现代化医院，2035年跨入国际一流行列。

**2、专科优势**

  //  

**（一）呼吸与危重症医学**

呼吸与危重症医学科有床位105张，设有呼吸普通病区、胸部肿瘤病区、内科ICU病区、呼吸内镜诊疗区；设有专科门诊及专病门诊（慢阻肺门诊、哮喘门诊、肺结节门诊、戒烟门诊）。呼吸门诊综合诊疗室可进行雾化吸入、结核菌素试验、诱导痰、皮肤点刺及脱敏等治疗。门诊及病房均设有肺功能检查室，可完成肺通气、支气管激发、支气管舒张、肺弥散、FeNO等检查。睡眠呼吸疾病诊疗室拥有2套多导睡眠监测仪，可常规开展睡眠呼吸监测。本着全面发展、突出专业特色的发展思路，本专科已经形成了慢性阻塞性肺疾病、哮喘、肺部感染、呼吸危重症、睡眠呼吸障碍、肺癌、介入呼吸病学、肺间质病、肺栓塞及肺血管病、烟草病学与呼吸疾病预防、肺康复等技术全面的专业学组，团队间相互协作，共同促进科室发展。在发展临床诊疗能力的同时，注重科研并举，成立科研小组，团队目前在研课题包括：国家自然科学基金4项，省重点研发计划项目2项，省自然科学基金2项。

我院呼吸内科及相关专业医师队伍是我省学术水平最高的专业团队。2017年成为全国首批专科医师培训基地，已通过PCCM专科基地认证，成为优秀专科基地，并申请PCCM专培、专修、单修基地，待审核通过，目前已招生5届专科学员。

呼吸与危重症医学科为国家药物临床试验基地，承担多项国内外临床药物试验，是国内承接临床药物研究数量及质量最好的单位之一。

**（二）重症医学科（内、外科危重症医学）**

重症医学科成立于1993年，是国家临床重点建设专科、海南省医学重点学科，目前有床位23张，属于成人综合性ICU，为编制独立的临床科室。科室拥有中央监护系统、移动式X光机、彩色多普勒超声诊断仪、经皮氧与二氧化碳分压监测仪、微创血流动力学监测仪、脉波指示剂连续心输出量监测仪、脑功能监测仪、无创颅内压监测仪、间接能耗监测仪、血气生化分析仪、快速免疫分析仪、容量及微量注射泵、高流量湿化氧疗仪、有创/无创呼吸机、纤维支气管镜、体外膜肺氧合器、主动脉内球囊反搏仪、多功能除颤起搏仪、临时心脏起搏器、血液净化治疗仪、亚低温治疗仪、吊塔、无线移动查房系统、双向可视对讲探视系统等先进仪器设备。从整体观念出发，利用先进的设备与技术，对重危患者的生命器官功能进行实时连续动态监测，及时判断病情变化的质与量并迅速采取医疗干预措施（包括生物医学工程技术上的超常规生命支持），帮助患者度过危及生命的不稳定状态、重建新的生理平衡，为进一步的专科诊治赢得时间和创造条件；承当临床教学与科研工作。

我院重症医学科承担医学本科生与研究生教学与培养任务。承担并完成国家、省、市各级科研项目14项，目前在研课题7项。获海南省科技进步二等奖1项、吴阶平医学基金科研成果三等奖1项、国家专利1项。主编出版著作4部，参编著作20余部，发表论文200余篇。

**（三）普通外科学**

我院普通外科是海南省建设规模最大的专科和海南省首批医学重点学科，包含肝胆胰外科、胃肠外科、肛肠外科、乳腺外科、血管外科、胸外科共10个病区。

我院普通外科专业医师队伍是我省学术水平最高的专业团队。团队中享受政府特殊津贴的专家2人，海南省有突出贡献的优秀专家2人。海南省“515”人才工程第一层次人才1名，海南省领军人才5名，南海名家3名。博士导师2名，硕士导师5名。拥有海南省医学会肿瘤分会主任委员1名、海南省抗癌协会胃癌专业委员会主任委员1名、海南省抗癌协会乳腺癌专业委员会主任委员1名、海南省抗癌协会大肠癌专业委员会主任委员1名、海南省抗癌协会癌症康复会主任委员1名、中华医学会肿瘤分会委员1名。担任数十种医学杂志的副主编、常务编委及编委。

我院普通外科团队主持完成获得的临床科研成果是省内获得最多的专科。先后获得省科技进步奖一等奖2项，二等奖7项、三等奖2项、四等奖1项。先后多人次获得中国医师奖、海南省医师奖、海南省优秀科技工作者、海南省青年科技奖。

**3、招收原则**

  //  

公开公平、自愿参加、双向选择、择优录取

**4、报名条件**

  //  

（一）完成住院医师规范化培训（以下简称住培）、取得合格证书并自愿参加专培的临床医师，申报专科应与住培专业来源一致。申报的培训专科与住培专业来源的对应要求见附表。

（二）以往未参加过住培但已经具备中级及以上专业技术职称的临床医师，根据工作需要、取得单位同意后，可申请参加培训，申报专科应与所在临床工作岗位相符合。

**招收专业、要求、培训年限及名额**

**5.报名流程**

01

**网上报名（7月30日- 8月5日）**

登陆中国医师协会“专科医师规范化培训管理平台”（网址https://st.ccgme-cmda.cn/login.html） 进行注册。请认真阅读《填报需知》，如实填写个人信息和志愿，提交报名信息。

02

**资格审核（8月6日至8月16日）**

● 医院对报名者材料进行现场审核，审核通过者参加考核。

● 时间：8月6日至8月16日正常上班时间

● 地点：海口市秀英区秀华路34-1号海南省人民医院临床技能中心规培办12楼1210室

● 审核材料：

（1）本人签名的报名表；

（2）委托培训人员提交由委派单位签字盖章的同意书；

（3）身份证原件及复印件；

（4）住院医师规范化培训合格证书原件及复印件；

（5）本科及以上学历（学位）证书原件及复印件；

（6）《医师资格证书》原件及复印件。

03

**考试时间（8月17日）**

理论考核时间统一为2022年8月17日上午9：00-11：00，各试点专科考核试题全国统一，采用网络视频手机在线闭卷考核，地点另行通知；

临床综合能力考核时间为2022年8月17日下午，具体安排由各专科负责，形式为现场面试，考试内容主要包括临床思维能力、临床实践能力、临床操作技能和临床沟通能力。

成绩评定：根据综合成绩评定（包括理论考核和临床综合能力考核，各占50%），择优录取。

**6、培训待遇**

  //  

专科培训学员在培训期间与本院同级别医师相同待遇。医院将按照社会保险相关规定为社招培训对象办理参保、缴纳社保费。对社招、委培培训对象，医院将提供免费或低收费住宿，不能安排住宿者发放住宿补贴200元/人/月。

**7、注意事项**

  //  

（一）对在招录工作中弄虚作假的培训申请人，取消报名和录取资格并上报卫健委；

（二）培训期间需遵守海南省人民医院专科医师职责、要求及培训考核规定；培训过程和结果不合格或有违反培训相关规定者，基地可调整培训计划、延期培训或退培；

（三）根据医院疫情防控工作要求，招生工作如有调整，将另行通知。
