# 孕妇能吃什么水果

> 更新时间：2026-09-15 (UTC+8)

孕妇能吃什么水果

水果是不少女士塑身营养圣品，营养师 表示水果也同样是准妈妈 和胎儿的营养圣品，只要吃对了水果，按指引的吃，对孕妇和宝宝都有极大的益处。营养师盘点出适合孕妇吃的水果，孕妇能吃什么水果?下面看看吧。

**目录**

1**孕妇能吃藠头吗**

　　藠头据说可以有安胎作用，孕妇有些喜欢吃口味重的，有些孕期反应比较腻味的，很适合时不时吃一点点，但是藠头也是属于刺激性的食物，和蒜是属于同类的，不但食物不能当药吃，而且还要注意少吃并且不宜做过于重口味的哦!

2**当归枸杞孕妇能吃不**

　　当归属于中药药材，很多地方的人们很喜欢煲汤时加入当归黄芪等中药材，养身健体。当归的首要功效，就是补血。血虚引起的头昏、眼花、心慌、疲倦、面少血色，脉细无力，最宜使用当归。

　　著名的当归补血汤，就由当归和黄芷组成。如果再加入党参、红枣，补养气血的功效更强，当归最宜用于妇女月经不调。虽然当归补血，但是专家提醒，当归这种药材女人在怀孕期间最好不要吃。

　　当归是治疗女性妇科的月经不调的常用药，有准妈妈反应，吃了当归做的汤后肚子发沉，出虚汗，所以小编还是建议女性在怀孕期间最好不要服用当归。

3**孕妇能吃什么水果**

　　Top1：安胎神医——葡萄

　　葡萄含有富含铁、磷、钙、有机酸、卵磷脂 、胡萝卜素 及维生素B1 、C等，孕妇血色不足、血压偏低、循环不好、冬天手脚冰冷 ，多吃葡萄可帮助改善，更特别的是，如果孕妇有出血现象，提子还有安胎作用，而且能帮助胎儿发育 。

　　Top2：“铁皇后”——樱桃

　　在所有水果中，樱桃所含的铁质特别丰富，称它为“铁皇后”当之无愧。樱桃几乎是苹果、橘子、梨的20倍，因此孕妇多吃樱桃，对胎儿很有帮助。妇婴专家表示，许多孕妇常吃樱桃，生下的宝宝多拥有一张红润的健康面容。

4**孕妇能吃肉脯吗**

　　孕妇需要慎吃猪肉脯。猪肉脯属于加工过的食物,其中的防腐剂和添加剂对婴儿的发育和成人的健康都是不利的,因此产妇最好不要吃过多。另外,该食品含有亚硝酸钠,长期使用容易致癌,因此,不管是大人还是小孩,都应适量。

5**孕妇吃什么蔬菜好**

　　1、黄豆芽能吃。孕妇多食黄豆芽对缓解妊娠性高血压有一定效果。但是黄豆芽性寒，慢性腹泻及脾胃虚寒尿多的孕妇忌食。

　　2、金针菇能吃。金针菇能有效地增强机体的生物活性，促进体内新陈代谢，有利于食物中各种营养素的吸收和利用。金针菇富含膳食纤维能促进胃肠的蠕动，有助于消化和防治便秘。因此孕妇适量的吃一些金针菇是很好的。

　　3、黄瓜能吃。黄瓜水分多、清甜可口，生吃能解渴清热，促进食欲。但黄瓜性寒凉，不宜多吃。最好炒熟吃。
